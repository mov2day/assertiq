Test Report Card

One command. Any JS/TS repo. A graded A–F report on your test suite quality. Think Lighthouse — but for tests. No configuration. No infra. Just run it.

terminal
$ npx test-smell-report-card
$ npx test-smell-report-card --html # pretty HTML report
$ npx test-smell-report-card --badge # write SVG badge

Quick start

Run in the root of any JavaScript or TypeScript project. No config file needed — the tool auto-detects your test framework from package.json.

💡

Results are fully static — no test execution happens. The tool reads and parses your source files only.

Grading dimensions

Each dimension is scored 0–100 then converted to a letter grade. The overall grade is a weighted average.

🔍
Assertion Quality
Detects tests with zero assertions, single generic asserts, and assertions that check structure rather than values. Tests that can never fail are flagged.
30%
⚡
Flakiness Risk
Scans for hardcoded setTimeout, sleep(), Date.now() in assertions, and hardcoded external HTTP URLs inside unit tests.
25%
🏷
Naming Clarity
Flags vague test names (test1, testFoo), names with no behaviour description, and missing Given/When/Then patterns in BDD suites.
15%
📊
Coverage Balance
Looks for happy-path-only suites missing error scenarios, exception paths, and edge cases. Also checks single-test-per-file ratios.
20%
💀
Dead Test Risk
Identifies skipped and ignored tests, xit / xdescribe / test.skip blocks, and commented-out test bodies that no longer run.
10%

Grade scale

A
90–100
B
75–89
C
60–74
D
45–59
F
0–44

Each letter grade carries + and - modifiers (e.g. B+, A-) at 3-point intervals within each band.

Supported frameworks

Framework detection is automatic via package.json dependencies. No config required.

// Auto-detected from your package.json jest → Jest vitest → Vitest @playwright/test → Playwright Test cypress → Cypress mocha → Mocha + Chai

CLI flags

Flag Description Default
--html Generate a styled HTML report at ./report-card.html off
--badge Write an SVG badge to ./test-report-card.svg off
--dir Path to scan (default: current directory) ./
--fail-below Exit with code 1 if overall grade drops below this level none
--json Output raw scores as JSON (useful for piping into dashboards) off
--ignore Glob patterns to exclude (e.g. --ignore "**/e2e/**") none

GitHub Action

Add to any repo in 3 lines. Posts a grade comment on every PR automatically.

1
Create .github/workflows/test-quality.yml in your repo
2
Paste the configuration below and commit
3
Every PR now gets an automatic grade comment with a breakdown of issues introduced
name: Test Quality Check on: [pull_request] jobs: report-card: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: muthu-kumar/test-smell-report-card@v1 with: fail-below: C # optional: fail CI below this grade post-comment: true

PR comment output

When post-comment: true is set, the Action posts a table comment on each PR automatically.

## 🧪 Test Smell Report Card | Dimension | Grade | Score | |-------------------|-------|-------| | Assertion Quality | B+ | 82 | | Flakiness Risk | D+ | 48 | | Naming Clarity | A- | 88 | | Coverage Balance | C+ | 71 | | Dead Test Risk | B | 78 | | **Overall** | **C+**| **72**| ⚠ 3 new test smells introduced in this PR.

Fail thresholds

Use --fail-below (CLI) or fail-below (Action) to enforce a minimum grade. The process exits with code 1 if the overall grade is below the threshold.

⚠

Thresholds use letter grades only: A, B, C, D, F. Plus/minus modifiers are not supported in thresholds.

# Fail CI if test suite falls below a B $ npx test-smell-report-card --fail-below B
