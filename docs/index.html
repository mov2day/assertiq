Rollout model

Progressive adoption path for enterprise repositories with policy, visibility, and governance built in.

01

Baseline

Run `npx assertiq --json` across repositories to establish current quality baseline.

02

Automate

Add GitHub Action with sticky PR comments and team-visible report artifacts.

03

Enforce

Apply `fail-below` policy per repo maturity and monitor trend movement in dashboards.

AssertIQ platform surface: CLI, Action, JSON, HTML, SVG badge Designed for engineering velocity with quality guardrails
